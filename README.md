A tiny program that writes one perfectly timed one-line comedy joke to `/output/entry.txt`. The joke lands in a single sentence: a proud office trophy on the surface, and a whole team quietly planning their exit underneath it — no setup paragraph, no second line needed.

## Run it

```sh
node main.ts
```

## About the joke

The line works because the mug's boast — "World's Best Boss" — is undercut in the same breath by the staff's real verdict: they were all quietly updating their résumés. The gift looks like praise until the second half reveals it as a farewell gesture, and that single turn is the whole punchline.
